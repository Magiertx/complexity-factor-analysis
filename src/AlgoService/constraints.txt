# Exact versions of every backend dependency, direct and transitive, as they run in the
# algoservice image on Python 3.11. requirements.txt keeps the ranges; this file makes an
# install repeatable, so a new release upstream cannot break a build or a test run by itself.
#
#   pip install -r requirements.txt -c constraints.txt
#   pip install -r requirements-dev.txt -c constraints.txt      (with the test tools)
#
# The Dockerfile and every pip install in .github/workflows/ci.yml use it. Constraints only
# limit versions, they install nothing: a package named here but not needed (uvloop on Windows)
# is ignored.
#
# To update: build a clean Python 3.11 environment without this file, install
# requirements-dev.txt, run `pip freeze`, and replace the two blocks below with the result.
# Then run the backend tests and `docker compose build algoservice`. See "Pinned dependency
# versions" in docs/DEPLOYMENT.md.
